# 概念学习资料生成 Skill

## 1. 适用场景

本 Skill 为通用设计，适用于任意新概念的系统性学习资料生成，包括但不限于：

- 学习新领域、新学科时，需要快速建立对一个陌生概念的整体认知；
- 备考或复习时，需要围绕某一核心概念整理结构化的学习笔记；
- 备课、汇报或写作时，需要梳理某个概念的要点、案例与易混淆点；
- 团队或个人知识管理中，需要将零散的概念信息整理为可复用的学习卡片。

只要用户给出一个概念（术语、理论、技术、方法、现象等均可），即可使用本 Skill 生成对应的学习资料。

## 2. 输入信息

用户需要提供的信息：

- **概念名称（必填）**：要学习的概念，可以是中文名称、英文名称或中英对照。
- **学习深度（可选）**：入门 / 进阶 / 专业，默认为"入门"。
- **目标读者（可选）**：默认为具有一般高等教育背景的学习者。
- **附加要求（可选）**：如侧重某一方面（历史脉络、数学推导、实践应用等）、指定输出语言、指定篇幅等。

若用户仅提供概念名称，其余项按默认值处理，不得因信息不足而中断流程。

## 3. 生成步骤

按以下固定顺序生成七个部分，各部分要求如下：

### 3.1 学习目标
- 明确列出学习者完成本资料后应达到的目标，使用可衡量的动词（如"能够定义""能够解释""能够区分""能够应用"）。
- 目标数量控制在 3—5 条，按认知层次由浅入深排列。

### 3.2 核心问题
- 提出围绕该概念的 2—4 个核心问题，这些问题应是学习者最关心、最能驱动理解的问题。
- 核心问题应与学习目标呼应，并在后文"结构化解释"中得到回答。

### 3.3 结构化解释
- 以清晰的层次结构（定义 → 背景/由来 → 关键要素/组成 → 运行机制/原理 → 边界与局限）解释概念。
- 先给出一句话定义，再逐步展开；对专业术语需在首次出现时用括号或脚注简要说明。
- 语言表述应通俗准确，避免堆砌名词而不解释。

### 3.4 应用案例
- 提供 2—3 个真实、具体的应用案例，覆盖不同情境（如理论场景与实践场景）。
- 每个案例需说明：情境是什么、概念在其中如何体现、结果或效果如何。
- 案例应尽量贴近目标读者的生活或专业背景。

### 3.5 概念辨析
- 选取 2—3 个与该概念易混淆的相邻概念，逐一对比。
- 建议使用对比表格（维度可包括：定义、关注点、适用范围、典型误解），并给出"一句话区分"。

### 3.6 自测问题
- 设计 5—8 道自测题，题型可混合：选择题、判断题、简答题、情境应用题。
- 每道题附参考答案与简要解析，解析需回扣"结构化解释"中的对应内容。
- 题目应覆盖全部学习目标，难度由易到难排列。

### 3.7 参考来源
- 列出资料中事实性内容所依据的来源，如教材、论文、权威网站、官方文档等。
- 来源格式规范（作者/机构、标题、出版或发布信息、链接或出处）。

## 4. 输出结构

最终输出采用 Markdown 格式，结构如下：

```
# 《概念名称》学习资料

## 一、学习目标
## 二、核心问题
## 三、结构化解释
### 3.1 一句话定义
### 3.2 背景与由来
### 3.3 关键要素
### 3.4 运行机制
### 3.5 边界与局限
## 四、应用案例
## 五、概念辨析
## 六、自测问题（含答案与解析）
## 七、参考来源
```

- 输出开头附一段 2—3 句的"导读"，说明本资料的适用对象与使用建议。
- 各级标题编号保持一致，正文段落简洁，优先使用列表与表格增强可读性。

## 5. 资料来源要求

- **必须可核查**：所有事实性内容（定义、数据、案例、人物、时间、出处）必须基于真实存在的来源，可通过检索工具核实后写入。
- **不得伪造**：严禁编造不存在的文献、论文标题、数据、网址或引文。若无法核实某一具体细节，应改用更宽泛但准确的表述，或明确标注"此处表述基于通识理解，建议进一步查证"。
- **来源分级**：优先使用权威来源（经典教材、官方文档、同行评审论文、权威机构网站），谨慎使用来源不明的自媒体内容；百科类网站可作为线索但不应作为唯一依据。
- **可追溯**：参考来源部分须提供足够的信息使读者能够找到原始出处（如 DOI、链接、出版信息）。

## 6. 自检要求

生成完毕后，逐项执行以下自检，全部通过方可交付：

1. **完整性**：七个部分（学习目标、核心问题、结构化解释、应用案例、概念辨析、自测问题、参考来源）均已生成，无遗漏。
2. **通用性**：内容针对用户本次输入的具体概念生成，未套用与概念无关的模板化空话。
3. **一致性**：核心问题在结构化解释中均有回应；自测问题覆盖全部学习目标；概念辨析中的对比维度清晰准确。
4. **准确性**：事实性内容经核实，参考来源真实可查，无编造的文献、数据或链接。
5. **可读性**：术语均已解释，层次清晰，符合目标读者的认知水平与设定的学习深度。
6. **格式**：输出结构与第 4 节规定的结构一致，Markdown 格式正确。

若自检发现不通过项，先修正再输出，交付时无需展示自检过程。
